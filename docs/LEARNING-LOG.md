# Learning Log

Append as you go, not at the end. One entry per thing you had not done before. Be specific: "learned X, was surprised by Y, here is what I would do differently" beats "learned React".

Format:

```
### [Slot] [Name] — [date]
**Learned:** …
**Surprise:** …
**Would do differently:** …
```

### M4 Vedika — 2026-09-26

**Surprise:** The hardest part of the spec was not the routes; it was deciding what counts as a data bug (a prerequisite cycle, a step without a source) and making it fail loudly at load rather than degrade quietly.
